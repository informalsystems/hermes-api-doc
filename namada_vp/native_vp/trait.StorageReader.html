Expand description

A convenience trait for reading and automatically deserializing a value from storage

Required Methods§

Source

fn read_pre_value<T: BorshDeserialize>(&self, key: &Key) -> Result<Option<T>>

Storage read prior state (before tx execution). It will try to read from the storage.

Source

fn read_post_value<T: BorshDeserialize>(&self, key: &Key) -> Result<Option<T>>

Storage read posterior state (after tx execution). It will try to read from the write log first and if no entry found then from the storage.

Provided Methods§

Source

fn must_read_pre_value<T: BorshDeserialize>(&self, key: &Key) -> Result<T>

Calls read_pre_value, and returns an error on Ok(None).

Source

fn must_read_post_value<T: BorshDeserialize>(&self, key: &Key) -> Result<T>

Calls read_post_value, and returns an error on Ok(None).
