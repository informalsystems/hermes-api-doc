Expand description

Type representing FF1 operations that can be performed on a sub-section of a NumeralString.

Source

fn numeral_count(&self) -> usize

Returns the number of numerals in this numeral sub-string.

Source

fn to_be_bytes(&self, radix: u32, b: usize) -> Self::Bytes

Returns a b-byte big-endian representation of the number that is encoded in base radix by this numeral string. The numerals are valued in decreasing order of significance (big-endian order). This corresponds to $STR^{b}{256}(NUM{radix}(X))$ in the NIST spec.

Source

fn add_mod_exp( self, other: impl Iterator<Item = u8>, radix: u32, m: usize, ) -> Self

Computes (self + other) mod radix^m.

Source

fn sub_mod_exp( self, other: impl Iterator<Item = u8>, radix: u32, m: usize, ) -> Self

Computes (self - other) mod radix^m.
