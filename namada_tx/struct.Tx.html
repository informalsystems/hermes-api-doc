pub struct Tx {
    pub header: Header,
    pub sections: Vec<Section>,
}
Expand description

A Namada transaction is represented as a header followed by a series of sections providing additional details.

pub fn validate_tx(&self) -> Result<Option<&Authorization>, TxError>

Determines the type of the input Tx

If it is a raw Tx, signed or not, we return None.

If it is a WrapperTx or ProtocolTx, we extract the signed data of the Tx and verify it is of the appropriate form. This means

  1. The wrapper tx is indeed signed
  2. The signature is valid
