Removes ascii whitespace from the end of this.

§Const stabilization

The equivalent std function was const-stabilized in Rust 1.80.0.

§Example

use konst::slice;

const TRIMMED: &[u8] = slice::bytes_trim_end(b"\rfoo bar  ");
