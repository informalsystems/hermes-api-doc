Expand description

tqdm like macro for creating Bar and BarIter.

It uses BarBuilder for creating Bar. See, all available methods.

§Panics

This macro will panic if BarBuilder::build returns error.

§Examples

use kdam::tqdm;

tqdm!();
tqdm!(total = 100);
tqdm!(total = 100, mininterval = 0.0, colour = "green");
tqdm!(0..100);
tqdm!(0..100, desc = "0 to 99");
tqdm!(["a", "b", "c", "d"].iter());
