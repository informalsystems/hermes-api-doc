pub fn iteration_key(revision_number: u64, revision_height: u64) -> Vec<u8> ⓘ
Expand description

This iteration key is namely used by the ibc-go implementation as an efficient approach for iterating over consensus states. This is specifically incorporated to facilitate cross-compatibility with ibc-go when developing CosmWasm-driven light clients with ibc-rs.

The key is formatted like so: iterateConsensusStates{BigEndianRevisionBytes}{BigEndianHeightBytes} to ensure that the lexicographic order of iteration keys match the height order of the consensus states.

See ibc-go documentation for more details.
